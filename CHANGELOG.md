## [1.0.0] - 2024-12-01

### Added
- Initial release of Rotation Lock
- Six orientation modes: Portrait, Landscape, Auto Rotate, Reverse Portrait, Reverse Landscape, Sensor Landscape
- Quick Settings Tile for toggling rotation lock from the notification shade
- Permission management flow for `WRITE_SETTINGS` special app access
- Dark / Light / Follow System theme support via DataStore Preferences
- Haptic feedback toggle
- Material 3 design with custom color palette
- Edge-to-edge layout support
- Android 7.0 (API 24) through Android 15 (API 35) compatibility
- GitHub Actions CI/CD pipeline
- Automated release workflow with SHA-256 APK checksum
